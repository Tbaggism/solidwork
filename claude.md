# Project Guidance

This repository is Jonathan Maynard's personal full-stack developer portfolio. For future site work, follow the [portfolio design specification](./spec.md):

- Use Midnight Blue `#0F3460` for the main background, Secondary Blue `#16537E` for layered surfaces, Ice Blue `#E8F4FD` for text, and Teal `#1ABC9C` for emphasis.
- Keep the cyberpunk direction refined and professional through a technical grid, terminal details, crisp borders, and restrained teal glow.
- Ground biography and work-history copy in the résumé at `src/assets/Jonathan_Maynard_Resume.pdf`. The owner identifies as a full-stack developer; do not infer unlisted employers, client work, project results, or current certifications.
- Use the current portfolio as the featured build until the owner supplies additional project details.
- Give text and content sections a subtle scroll reveal. Use the existing `ScrollReveal` behavior, `transform`/`opacity` only, staggered entry, and reduced-motion support.

Prefer shared CSS variables, semantic HTML, responsive layouts, visible keyboard focus, and accessible contrast. Avoid adding unrelated template routes or unnecessary UI dependencies.
